# M0-H1 · 原生访问隔离探索

- 动作：探索。
- 输入：R0、已确认 CLI 项目边界、D5（CLI 暂定 Lean）、M0-L1 的可运行工具链。
- 目标：普通沙箱命令不能直接读写真实仓库；受控 CLI 可执行允许操作；用户决定入口不能由 agent 使用。
- 范围：独立假仓库、导出视图、另一任务的假目录、测试 CLI 及命令级配置。使用已安装的原生 Windows sandbox。
- 接纳条件：保存真实执行结果；规则匹配、沙箱访问、例外分派分别取证，不能相互代替。
- 边界：这是接入探针；不代表完整 CLI 或可信内核已经实现。

任何需要变更全局配置、新建系统账号或调整试验目录外权限的步骤，先具体化范围再交由用户评估。本包不修改当前任务或其他任务的权限设置。
