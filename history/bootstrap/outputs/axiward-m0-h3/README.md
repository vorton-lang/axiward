# M0-H3 用户决定与恢复协议验证

2026-09-18 · **本轮协议对照通过；用户侧答复由受信测试客户端模拟。**

测试使用原生 MCP 用户输入通道。执行者只能请求提问，不能从工具参数里提交决定或自称用户。用户侧回调先核对作用范围、持久保存决定，再回复原工具调用。

| 对照 | 结果 |
| --- | --- |
| 执行者提交 `decision=approve, source=user` | 拒绝；没有形成决定 |
| 用户侧回调回答当前问题 | 决定绑定问题、产物摘要与规格摘要 |
| 提问后产物版本变化 | 保留过期答复记录，但不应用该答复 |
| 正常回复原工具调用 | 原生记录确认问题和完成事件属于同一指定任务 |
| 决定保存后、通知前适配进程退出 | 原任务收到通道错误；决定文件仍在，通知仍记为待处理 |

这说明：记录决定与通知任务可以分开处理，通知失败不必丢失已经收到的决定。
