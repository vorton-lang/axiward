# M0-L2 · 固定规格下的证明接纳

- 动作：探索；输入为 Q0、L1 实现、Lean 4.34.0、D5、D6。
- 控制端持有规格、目标定理、审查规则、构建配置和结果记录。
- 候选只提供队列实现与证明；已有编译缓存不作为证明依据。
- 检查：固定目标、公理依赖、候选声明的运行替换、内核重放、源码与产物绑定。
- 对照：正确实现、错误 FIFO、偷换目标、未授权公理、sorry、旧证明、运行实现替换、产物篡改。
- 当前前提：完全访问权限＋访问规则。检查器与记录存储由控制端维护；尚不抵抗候选恶意篡改进程、工具链或控制端文件。
- 产物：Lean 编写的接纳探针、固定目标与审查文件、可复现对照结果。探针本身的完整形式验证属于后续 M1，不在本包冒充已完成。
