# Axiward 初版访问规则

2026-09-18 · 用户允许当前原型使用完全访问权限，以规则文本约束执行者。以下是行为规范，尚非操作系统强制隔离。

1. 工作包执行者只直接读写分配给该包的视图；正式仓库、根规格、系统状态、检查器及其他受限材料，经 Axiward 的授权入口访问。
2. 候选实现与证明写入当前视图；正式结果通过 CLI 提交，不能直接修改仓库来模拟“接纳”。
3. 不改检查器、访问规则、工具配置或既有证据来使当前候选通过。失败、未知与证据失效如实保留。
4. `decide` 属于用户入口。Agent 可以准备待决问题，不得代用户作出或伪造确认。
5. 控制端初始化、验收与故障注入使用各自明确的试验范围；不能把这些维护权限转交给工作包执行者。
6. 外部调研与通常工具使用继续按已有授权进行；调用结果依既定证据规则接纳。

正式仓库的目录边界与系统规范继续保留。当前 full-access 原型依赖执行者遵守本规则，尚不能抵抗故意绕开入口的执行者。
