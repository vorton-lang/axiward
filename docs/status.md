# 项目状态

**当前目标：本机 Windows + Codex 的独立 CLI。路线失效回收、共享源码合入与失败诊断交接已实现。** 具体见[发布路线](roadmap.md)。

| 项目 | 当前事实 |
| --- | --- |
| 已实现的基础 | 四类工作包、Git 正式状态与普通签出、包级工作空间、固定输入、完整交接、暂停恢复、规格变更和成果复用。 |
| 文件布局 | 核验 `.checks/` 和默认交付 `delivery/` 位于项目根并忽略；每包根保留候选、规格、目标与唯一 `AGENTS.md`，连接配置在 `.codex/`，视图、按需材料和临时文件在包内 `.axiward/`。完整证据仅显式导出；封存仍使用动作白名单。旧用户目录不自动迁移或清理。 |
| Worker 模式 | 完全访问权限加说明约定；工具入口仍检查参数、归属和准入，不声称操作系统强制隔离。 |
| 验证接入范围 | 当前支持 Lean FIFO 的两个登记规格；这不是通用软件验证器，也不表示 Axiward 已经自我管理。 |
| 当前验证 | 包布局、只读查询、完整诊断、访问拒绝与草稿保留已通过独立检查；真实 Lean 失败样本与协议/IO 夹具分开记录，单次不超过 30 秒，见[工程说明](execution-slice.md#验证与边界)。旧检查重整只达到 checkpoint，未宣称全面完成。 |
| 本机发行 | 独立打包脚本与必要运行文件已具备，脱离源码目录启动和适配器 stdio 预验通过；发行版本由生成目录的 release.json 标明。旧原生接入复验及最终用户使用验收尚未完成。 |

旧版本或长串联脚本的通过记录不能替代当前版本的覆盖声明。协议检查中的用户答复是明确的测试输入，不是真实产品批准；真实 agent 持续推进与最终用户验收没有因此完成。

当前控制器支持范围、发布边界和编译/运行证据分别由[设计](design.md)、[发布路线](roadmap.md)、[工程说明](execution-slice.md)记录。运行方式见[使用说明](product-guide.md)，完全访问模式的边界见[执行模式](permissions.md)。
