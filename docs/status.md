# 项目状态

**当前目标：本机 Windows + Codex 的独立 CLI。发布前还有两个设计议题待定：项目完成条件，以及多包源码合入规则。** 具体见[发布路线](roadmap.md)。

| 项目 | 当前事实 |
| --- | --- |
| 已实现的基础 | 四类工作包、Git 正式状态与普通签出、包级工作空间、固定输入、完整交接、暂停恢复、规格变更和成果复用。 |
| Worker 模式 | 完全访问权限加说明约定；工具入口仍检查参数、归属和准入，不声称操作系统强制隔离。 |
| 验证接入范围 | 当前支持 Lean FIFO 的两个登记规格；这不是通用软件验证器，也不表示 Axiward 已经自我管理。 |
| 当前实施 | 已批准按定理、纯逻辑缺口和外部边界重整检查，单次不超过 30 秒。该项实施中，结果与覆盖见[工程说明](execution-slice.md#验证与边界)。 |
| 发布剩余工作 | 完成检查重整，定案并实现两个设计议题，整理本机可用的二进制与必要运行文件。 |

旧版本或长串联脚本的通过记录不能替代当前版本的覆盖声明。协议检查中的用户答复是明确的测试输入，不是真实产品批准；真实 agent 持续推进与最终用户验收没有因此完成。

当前控制器支持范围、未决规则和编译/运行证据分别由[设计](design.md)、[发布路线](roadmap.md)、[工程说明](execution-slice.md)记录。运行方式见[使用说明](product-guide.md)，完全访问模式的边界见[执行模式](permissions.md)。
