# 0.2.0 · 薄适配器权限接入

**本版补齐的是项目访问边界。** 旧版只限制 MCP 工具，普通命令仍能绕过；本版把原生权限与薄适配器接通，候选核验也在受限进程里执行。

你需要知道的变化：

- 正式仓库、控制端和核验目录不向普通 worker 开放。worker 通过适配器读取允许的视图、提交候选和请求用户决定。
- 复制 CLI 不能获得用户权限；链接文件不能借适配器读取私有内容。旧的完全访问配置、放宽了边界的配置会被拒绝。
- 同项目的核验工具使用项目内互斥锁；编写工作和其他项目不被锁住。原生网络与外部资料读取仍可用于调研。
- 源码、原型、实验失败与成功记录都在本仓库；[项目状态](../status.md)直接说明现在能做什么和下一道门槛。

## 使用边界

当前接入限 Windows 原生 Codex 与生成的权限配置，产品验证器限 Lean FIFO 两个规格。操作系统、原生 sandbox、控制端和验证工具链仍是声明的信任前提；这些检查不等于对所有可能的工具和系统漏洞做了安全证明。

真实 agent 的持续推进和导航效果尚未实战验收。距离最初的开放产品目标，仍需规格生成接入、更多验证器及真实任务验证。

使用[产品说明](../product-guide.md)创建新受限视图。不要继续使用 0.1 生成的完全访问任务。构建与打包由[仓内脚本](../../scripts/package.ps1)完成，输出放在 `dist/`。
